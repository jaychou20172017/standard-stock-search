# 标准品现货搜索skill

中文 | [English](README.en.md)

英文使用、需求、项目状态与验收文档见[英文首页](README.en.md)。两种语言共用代码；当前Excel标签、命令提示及枚举值仍为中文，英文使用说明提供字段对照，不宣称运行界面已完整英文化。

按品牌、完整型号、数量和收货地搜索全新原装现货，优先中国大陆，按条件扩展全球，输出三页Excel。单产品可聊天填写，多产品使用Excel模板。

## 使用与状态

技能目录为`standard-stock-search/`，操作方式见[使用说明](使用说明.md)，能力及实测限制见[验收记录](验收记录.md)。当前交付版本为v0.1.12，在v0.1.11基础上增加中英文文档与英文许可译文，其他客户端及另一台电脑实测后续进行。
